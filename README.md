# LLM Classification Finetuning

## Постановка задачи

Необходимо обучить модель для предсказания ответа, который предпочёл пользователь в рамках соревнования двух моделей на Chatbot Arena. Подробно с задачей можно ознакомиться [здесь](https://www.kaggle.com/competitions/llm-classification-finetuning/overview).

### Формат входных и выходных данных

Входные данные представляют из себя файл размером около 57 тысяч записей и 5 столбцов в формате CSV. Выходные данные представляют из себя файл размером около 25 тысяч записей и 4 столбцов в формате CSV.

### Метрики

Решаемая задача - задача мультиклассовой классификации, для неё подойдут следующие метрики: Accuracy, Precision, Recall, F1. Рассчитывать эти метрики можно по трём стратегиям: микро-усреднение, макро-усреднение, взвешенное усреднение - я остановлюсь на макро-усреднении. Главной метрикой оценкой качества решения будет log-loss между предсказанными значениями и реальными, как это делается в самом соревновании на Kaggle.

### Валидация и воспроизводимость

Обучающая и тестовая выборки уже выделены за меня. Выборку для валидации я планирую выделять самостоятельно через стратифицированный по значениям целевых переменных train-test-split с фиксированным random state.

### Данные

Обучающая и тестовая выборка содержат следующие атрибуты:

- id - уникальные идентификатор записи.
- model\_[a/b] - название моделей a и b. Атрибут есть только в обучающей выборке.
- prompt - входной промпт для обеих моделей.
- response\_[a/b] - ответ моделей a и b.
- winner*model*[a/b/tie] - целевая переменная, флаг победителя или ничьи.

Особенностью данных является их структура - это текстовые данные, поэтому, прежде чем с ними работать, их придётся трансформировать в векторное представление.

Данные находятся [здесь](https://www.kaggle.com/competitions/llm-classification-finetuning/data?select=train.csv).

## Моделирование

### Baseline

- Baseline — sentence-transformer + LogisticRegression.
- Быстро показывает базовый чекпоинт качества и пригоден для сравнения с обучением трансформеров.

### Основная модель

- Основная стратегия — многослойная модель мультиклассовой классификации, обученная на эмбеддингах из sentence-transformer.

## Внедрение

Предполагаю, что модель должна использоваться в виде сервиса с интерфейсом (Streamlit), быть развёрнутой внутри Docker-контейнера (Kubernetes для масштабирования) через свой backend, реализованный на FastAPI, со всеми интструментами в виде code-formatter & linter (ruff), dvc, uv и так далее. Сервис должен принимать на вход данные в виде CSV и возвращать предсказания в таком же формате.

# Setup

Для работы с проектом необходимо выполнить следующие действия:

1. Выполнить команду `git pull https://github.com/113578/llm-classification-finetuning.git`.
2. Выполнить команду `uv sync`.
3. Настроить конфигурации в папке `configs/` по вкусу.
4. При необходимости выполнить команду `export PYTHONPATH=.`.
5. Выполнить команду `uv run mlflow server --host 127.0.0.1 --port 8080`.
6. Выполнить команду `uv run tensorboard --logdir tensorboard_logs`.

# Train

Для версионирования данных в проекте используется dvc с локальным хранилищем, поэтому прежде чем запустить тренировку необходимо скачать данные, для этого можно воспользоваться командой `uv run commands.py download_data --dataset_url 'a63768/llm-classification-finetuning' --target_dir 'data/'`.

Для запуска обучения модели используется команда `uv run llm_classification_finetuning/train.py`, по окончанию обучения сохранится state dict модели вместе с логами, расположение которых указано в конфигуациях проекта.

Для запуска инференса модели используется команда `uv run llm_classification_finetuning/infer.py`, по окончанию инференса в папку с артефактами модели сохранится выборка с предсказаниями.

Все логи обучения сохраняются в MLflow и TensorBoard.
